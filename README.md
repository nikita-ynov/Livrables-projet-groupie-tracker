## 🚀 Description

**Groupie Tracker** est une application permettant de suivre, analyser et afficher des informations liées à des groupes/artistes et leurs communautés (fans, événements, données associées).

Ce projet a été réalisé dans le cadre d'un travail de groupe, avec pour objectifs :
- la mise en place d'une architecture propre,
- l'exploitation de données via une API,
- la création d'une interface claire et fonctionnelle,
- la livraison d'un projet documenté et exploitable.

---

## 📦 Fonctionnalités

- 🔍 Recherche de groupes/artistes  
- 📊 Affichage des informations (dates, lieux, relations, etc.)
- 🖥 Interface web dynamique
- 🔄 Communication entre frontend et backend
- 🗃 Gestion et structuration des données
